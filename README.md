# The Treasure of Tensor Island

Exercises on tensor network renormalization (TNR): write your own tensor renormalization group (TRG) in
Python and compute the free energy of the 2D Ising model on a lattice of $2^{30} \approx 10^9$ spins, to
five digits of Onsager's exact solution.

The notebook is a pirate-themed treasure hunt. Each "island" is one step of the algorithm, with hints folded
under every task and a checkpoint cell that tells you whether your code is right before you sail on.

| Stop | What you do |
|---|---|
| 0 Port Royal | load the toolbox, conventions, `np.einsum` refresher |
| 1 Tortuga | derive the Ising site tensor `T[l, d, u, r]` |
| 2 Shipwreck Cove | split a tensor with a truncated SVD |
| 3 Fort Charles | write one Levin–Nave TRG step |
| 4 The Maelstrom | iterate, normalize, and get the free energy |
| 5 Isla de Muerta | the final test against Onsager (χ = 16, 30 RG steps) |
| 6 The real treasure | an introduction to [TNRKit.jl](https://github.com/QuantumKitHub/TNRKit.jl) |
| 7 World's End | extras: accuracy vs χ, magnetic field, observables, critical exponents, central charge and scaling dimensions |

## Files

- [TNR_treasure_hunt.ipynb](TNR_treasure_hunt.ipynb): the exercise notebook. Start here.
- [TNR_treasure_hunt_solutions.ipynb](TNR_treasure_hunt_solutions.ipynb): complete solutions, with a table
  linking each exercise function to its TNRKit.jl counterpart.
- [tools/build_notebooks.py](tools/build_notebooks.py): generates both notebooks from a single source.

## Getting started

No prior knowledge of TNR is needed; you should be comfortable with Python and numpy (`reshape`,
`transpose`, `np.linalg.svd`).

The easiest way to run the notebook is in Google Colab, where numpy, scipy and matplotlib are already installed:

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/JaridPiceu/Introduction-to-TNR-Exercises/blob/main/TNR_treasure_hunt.ipynb)

To run it locally, install the dependencies and open the notebook in Jupyter or VS Code:

```bash
pip install numpy scipy matplotlib jupyter
jupyter notebook TNR_treasure_hunt.ipynb
```

## Editing the notebooks

Both notebooks are generated by `tools/build_notebooks.py`. Make changes there, then rebuild from the repo root:

```bash
python tools/build_notebooks.py .
```

This overwrites both notebooks, so port any edits made directly in a notebook to the script first.
